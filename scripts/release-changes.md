## この版の主な変更（0.1.1-beta.1 から）

<!-- 出すたびに、この版の変更に書き直す（make publish が、リリースの説明の先頭に入れる） -->

0.1.0・0.1.1 を入れている場合は、アプリの中から更新できます（メニューバーのアイコン →「アップデートを確認…」。自動でも確かめます）。棚の中身と設定は、そのまま残ります。

### 変わったこと

- 使い方・見た目・動きは変わりません。開発と配布の手順を整えた版です
- 0.1.0 より前の β 版（ID `app.pinshelf.Pinshelf`）とは別のアプリとして扱われるので、前の版からは更新されず、棚と設定も引き継がれません。前の版を使っていた場合は、ここから入れ直してください（前の版はゴミ箱に入れてかまいません）

**English:** Nothing changes in how Pinshelf looks or works; this release only tidies up the development and release process. If you have 0.1.0 or 0.1.1, you can update from the menu bar ("アップデートを確認…"); shelves and settings are kept. Betas before 0.1.0 (app ID `app.pinshelf.Pinshelf`) do not update to this version, so please install it fresh.
