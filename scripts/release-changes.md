## この版について（0.1.0）

<!-- 出すたびに、この版の変更に書き直す（make publish が、リリースの説明の先頭に入れる） -->

アプリの ID と署名を新しくして、0.1.0 から出し直した最初の版です。機能は 0.3.2-beta.1 と同じです。

- アプリの ID を `app.nexy.Pinshelf` にしました。前の β 版（ID `app.pinshelf.Pinshelf`）とは別のアプリとして扱われるので、前の版からは更新されず、棚と設定も引き継がれません。前の版を使っていた場合は、ここから入れ直してください（前の版はゴミ箱に入れてかまいません）
- 作者の証明書（nexy Release Signing）で署名するようにしました。これから先の版は、どれも同じ証明書で署名するので、更新しても macOS の確認は出ません

**English:** This is the first release after changing the app ID to `app.nexy.Pinshelf` and signing it with the author's own certificate. Features are the same as 0.3.2-beta.1. It does not update from earlier betas (different app ID), so please install it fresh; shelves and settings from earlier betas are not carried over.
