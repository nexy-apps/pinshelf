## この版の主な変更（0.1.0-beta.1 から）

<!-- 出すたびに、この版の変更に書き直す（make publish が、リリースの説明の先頭に入れる） -->

- 設定の「出し方」の見出しと説明の文を整えました。機能は 0.1.0-beta.1 と同じです
- 0.1.0 より前の β 版（ID `app.pinshelf.Pinshelf`）とは別のアプリとして扱われるので、前の版からは更新されず、棚と設定も引き継がれません。前の版を使っていた場合は、ここから入れ直してください（前の版はゴミ箱に入れてかまいません）

**English:** Reworded the labels and descriptions in the "出し方" settings. Features are the same as 0.1.0-beta.1. Betas before 0.1.0 (app ID `app.pinshelf.Pinshelf`) do not update to this version, so please install it fresh; shelves and settings from those betas are not carried over.
